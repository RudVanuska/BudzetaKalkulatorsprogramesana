# GUI prototips

Programmas logs ir veidots vertikāli, lai lietotājs darbības veiktu no augšas uz leju. Vispirms lietotājs ievada datus, pēc tam pievieno ierakstu, apskata sarakstu un apakšā redz aprēķinu rezultātu.

```text
+------------------------------------------------+
|              Budžeta plānotājs                 |
| Ievadi ienākumus vai izdevumus un apskati...   |
|                                                |
| Nosaukums:      [____________________]         |
| Summa (€):      [____________________]         |
| Kategorija:     [Ienākumi / Izdevumi]          |
|                                                |
|              [ Pievienot ierakstu ]            |
|                                                |
| +--------------------------------------------+ |
| | Alga | Ienākumi | 600.00 €                 | |
| | Pārtika | Izdevumi | 45.50 €               | |
| +--------------------------------------------+ |
|                                                |
| [ Dzēst izvēlēto ]       [ Notīrīt visu ]      |
|                                                |
| Ienākumi: 600.00 €                            |
| Izdevumi: 45.50 €                             |
| Atlikums: 554.50 €                            |
| Budžets ir pozitīvs.                          |
+------------------------------------------------+
```

## Saskarnes elementi
Ievades lauki: nosaukums un summa. Izvēlne: kategorija. Pogas: “Pievienot ierakstu”, “Dzēst izvēlēto”, “Notīrīt visu”. Izvades elementi: ierakstu saraksts un rezultāta teksts.
